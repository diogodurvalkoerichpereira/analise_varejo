# Instruções de execução

**Aluno:** Diogo Durval Koerich Pereira  
**Turma:** T3

1. Baixe ou clone o repositório e abra a pasta no VS Code.
2. Confirme que `dados/Base Varejo.csv.zip` está presente.
3. Instale as dependências com `pip install -r requirements.txt`.
4. Execute `python analise_varejo.py`.
5. Consulte a pasta `resultados`, que conterá a base limpa, tabelas, gráficos, conclusões e o relatório do terminal.

Também é possível enviar a pasta ao Google Colab, instalar as dependências e executar o script. Para informar outro arquivo, use:

```bash
python analise_varejo.py --arquivo "caminho/Varejo.csv"
```
